# Quick Start Guide

## Running the Application

### Option 1: Two Terminals (Recommended)

**Terminal 1 - Backend:**
```bash
cd backend
npm start
```

**Terminal 2 - Frontend:**
```bash
npm run dev
```

### Option 2: Single Commands

**Backend:**
```bash
npm run backend
```

**Frontend (separate terminal):**
```bash
npm run dev
```

## Access Points

- **Frontend**: http://localhost:5173
- **Backend**: http://localhost:5001
- **Admin Login**: http://localhost:5173/admin

## Admin Credentials

- Username: `admin`
- Password: `admin@123`

## What's Included

✅ Express backend with session-based authentication
✅ Admin login page at `/admin`
✅ Protected admin dashboard at `/admin/dashboard`
✅ Logout functionality
✅ CORS configured for frontend-backend communication
